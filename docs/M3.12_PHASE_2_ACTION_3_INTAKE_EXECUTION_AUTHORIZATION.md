## Reproducible execution

The evidence below was produced by building the repository (`npm run build`)
and invoking the compiled adapter directly:

```
node -e '
const { M3_REHEARSAL_OPT_IN, M3RehearsalAdapter } = require("./dist/src/app/m3-rehearsal-adapter.js");
const adapter = new M3RehearsalAdapter();
const evidence = adapter.run({
  id: "m3.12-rehearsal-request-1",
  stationId: "station:m312a",
  idempotencyKey: "m3.12-phase2-rehearsal-key-1",
  actionId: "m3.12-phase2-action3-intake-execution",
  fixtureReference: "m3.12-fixture-ref:sha256:672e20407e7dc9b30bc736953614675fd433da4b51e73b3f5e40a31724b25959",
  activation: M3_REHEARSAL_OPT_IN,
  metadataMode: "deterministic_double",
});
console.log(JSON.stringify(evidence));
'
```

This is deterministic: re-running it against a clean adapter instance
produces byte-identical evidence, because the adapter never reads real
state.
