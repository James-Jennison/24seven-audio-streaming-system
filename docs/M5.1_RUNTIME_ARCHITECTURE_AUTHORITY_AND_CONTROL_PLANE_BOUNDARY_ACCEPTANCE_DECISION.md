# M5.1 Runtime Architecture, Authority, and Control-Plane Boundary Acceptance Decision

## Decision and boundary

**Status: accepted 2026-08-05 UTC; local-only and non-operational.** This
decision accepts the [M5.1 runtime architecture, authority, and Control Plane
boundary](M5.1_RUNTIME_ARCHITECTURE_AUTHORITY_AND_CONTROL_PLANE_BOUNDARY.md).
It accepts only an in-memory, unavailable-only authority/observation contract;
it does not accept or activate a runtime implementation.

The M3 and M4 accepted local-only boundaries remain unchanged. `Published
(Versioned)` is not `Executed (Runtime)`, and this decision creates no Control
Plane command path into the Playout & Automation Runtime or any other plane.

## Accepted evidence

| Required criterion       | Accepted evidence                                                                                                                                                                        |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Writer authority         | A fixed four-plane matrix permits only the Control Plane to write programming state and only the future Runtime to write runtime observations. Output control is `none` for every plane. |
| Safe unavailable posture | The sole modeled observation is versioned `unavailable` / `safe_stop`; any richer state is rejected.                                                                                     |
| Station isolation        | Every record/lookup requires `id + station_id`; public out-of-scope lookup returns `not_found` and trusted mismatch returns `station_reference_forbidden`.                               |
| Content-free telemetry   | Contract output contains only opaque identifiers, fixed status/category fields, UTC time, and sequence; focused coverage rejects content and sensitive fields.                           |
| No operational path      | Static coverage verifies no process, persistence, filesystem, network, device, encoder, relay, Icecast, or downstream adapter/import.                                                    |

The focused compiled test and complete local repository suite passed: Prettier,
ESLint, strict TypeScript, 122 Node tests, dependency audit with no high-or-
higher findings, and public-repository hygiene. No media, PostgreSQL,
migration, container, worker, process, provider, runtime, encoder, relay,
Icecast, listener, DNS, deployment, staging, or production action occurred.
