## Decision and strict non-authority

**Status: accepted 2026-08-05 UTC by the repository owner
(codeframe@gmail.com); documentation-only and non-operational.** This is the
one-action `media_access_authority` approval required before any rehearsal
action may reference the `minimal_rehearsal_cohort`. It authorizes exactly
one synthetic, non-media fixture reference for use only by the
[`M3RehearsalAdapter`](../src/app/m3-rehearsal-adapter.ts) deterministic

**No real media is selected, named, accessed, copied, or imported by this
decision or by any action it authorizes.** The adapter has no filesystem,
process, network, or provider access; it cannot read a real file even if one
were named.

## What this authorization does not permit

It does not authorize selecting, naming, copying, accessing, or importing any
real media asset, path, filename, or title. It does not authorize a second
fixture, a different cohort, or a broader station scope. Completion of this
action authorizes neither a retry nor any broader scope; it authorizes only
the intake-execution gate below, and only for this exact fixture reference.
