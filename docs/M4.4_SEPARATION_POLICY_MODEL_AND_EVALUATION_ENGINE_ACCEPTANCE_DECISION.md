# M4.4 Separation-Policy Model and Evaluation Engine Acceptance Decision

## Decision and boundary

**Status: accepted 2026-08-05 UTC; local-only and non-operational.** This
decision accepts [M4.4's separation-policy model and evaluation
engine](M4.4_SEPARATION_POLICY_MODEL_AND_EVALUATION_ENGINE.md) under its
separate owner approval. It accepts only deterministic, in-memory evaluation
of approved opaque inputs; it does not create a schedule.

It authorizes no M4.5 preview work, catalog/asset mutation, metadata
enrichment, database connection, migration, schedule generation, approval,
publication, runtime enforcement, encoder, Icecast, deployment, or production
activity.

## Accepted evidence

| Required criterion          | Accepted evidence                                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Approved policy input       | Policies require an approved state, opaque identity, station scope, minimum distance, and deterministic precedence.                        |
| Conflict and precedence     | Conflicting opaque keys return a controlled category; the lowest precedence policy wins deterministically.                                 |
| Empty and incomplete inputs | Empty selection returns `catalog_empty`; missing required keys return the fail-closed `separation_key_unavailable` category.               |
| Station isolation           | Public other-station reads return `not_found`; trusted candidate/policy ownership mismatch returns `station_reference_forbidden`.          |
| Content-free output         | Results contain only opaque IDs and safe outcome/category fields, with no media, metadata, title, artist, path, credential, token, or SQL. |
| Non-dispatch                | Static coverage proves no filesystem, network, persistence, worker, runtime, encoder, relay, or Icecast adapter import or invocation.      |

The focused compiled test and full repository quality suite pass. M4.4 did not
access media or metadata, connect to PostgreSQL, execute a migration, start a
process or service, generate a schedule, publish, or contact runtime, encoder,
relay, Icecast, listener, DNS, deployment, or production systems.

## Next gate

At the time of this decision, **M4.5 — Dry-run generation, conflict reporting,
and preview** was the next sequential milestone and required a new explicit
owner approval before work began. This decision neither granted nor implied
that approval.
