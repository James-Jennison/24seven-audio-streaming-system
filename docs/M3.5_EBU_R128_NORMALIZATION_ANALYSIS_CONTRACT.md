# M3.5 EBU R128 Normalization Analysis Contract

**Status: local-only, disabled, and non-operational.** M3.5 defines a
station-scoped EBU R128 normalization-analysis request/result contract. It does
not read media, perform EBU R128 measurement, modify audio, apply gain, start a
worker, or activate persistence.

The contract accepts only an M3.4-approved opaque processing job whose same-
station asset revision is approved and whose source validation is valid. A
request contains opaque IDs, the `ebu-r128-v1` profile, bounded target/gain
policy, analysis-version ID, and retry count. No path, filename, URL, tag,
payload, metadata, credential, or token is accepted or exposed.

The disabled boundary returns deterministic fixture-preview or unavailable
outcomes only. Fixture values are explicitly marked `analysisPerformed: false`
and `deterministic_fixture`; they are not claims of real EBU R128 analysis.
Measured loudness, loudness-range, true-peak, target, and recommended-gain
values use bounded validators. A recommendation remains a derived future
suggestion, never an approved DSP setting or an asset-revision update.

Requests, results, and evidence use `id + station_id`. Out-of-scope reads
return `not_found`; internal cross-station references return
`station_reference_forbidden`. Idempotent duplicate requests return their
original immutable result; conflicts, invalid policy, ineligible jobs, and
unsupported retry states produce safe declined categories. Results and evidence
are append-only intent and cannot overwrite asset provenance or a prior
recommendation.

The read-only API/UI status is disabled/fixture-only. There is no analyze-now,
upload, dispatch, worker, filesystem, network, provider, schedule, runtime,
encoder, relay, Icecast, or listener-facing action. Evidence contains only
action, opaque ID, station ID, profile/version, safe category/count, timing, and
bounded technical values.

This work belongs only to the Programming Control Plane. PostgreSQL remains the
sole future live store; no SQLite, SAM, PAL, SHOUTcast, migration, staging
activation, or operational normalization was introduced. M5 remains the future
owner of DSP and gain application.

The next permissible item is separately approved **M3.6 — cue, fade, duration,
and quality-analysis contract**. External tooling, worker/persistence/staging
activation, or real-media normalization require separate explicit approval and
content-free evidence.
