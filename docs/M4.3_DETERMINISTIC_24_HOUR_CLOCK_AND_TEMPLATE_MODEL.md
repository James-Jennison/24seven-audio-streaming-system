# M4.3 Deterministic 24-Hour Clock and Template Model

## Status, purpose, and authority

**Status: local-only Control Plane contract and deterministic fixture boundary;
non-operational.** M4.3 defines station-local opaque clock templates, ordered
slots, IANA timezone validation, and a 24-hour civil-day planning input. It is
the execution record for [M4.3 in the authoritative roadmap](ROADMAP.md#m43--deterministic-24-hour-clock-and-template-model) and depends on accepted M4.1 and M4.2.

M4.3 authorizes no live wall-clock control, instant conversion, queue mutation,
asset/catalog query, media analysis, schedule generation, approval,
publication, persistence, runtime timing, encoder, Icecast, deployment, or
production activity.

## Template and ordering contract

A template requires `id + station_id`, a valid IANA timezone, a positive
revision, and opaque slots. Each slot has only an opaque ID, a local start
minute, and a duration. Sorted slots must be contiguous and cover exactly the
1,440 local minutes of a civil day; gaps, overlaps, out-of-range values, empty
templates, and invalid timezones are rejected.

`M4ClockTemplateBoundary` snapshots and freezes every template and slot on
ingest. `prepareDayInput(station_id, template_id, local_date)` returns a frozen,
deterministically ordered civil-day input with opaque identifiers, timezone,
template revision, local date, safe slot counts, and
`execution: unavailable`. It contains no assets, media, metadata, titles,
artists, filenames, paths, URLs, credentials, tokens, raw SQL, or schedule
content.

## Timezone and DST boundary

M4.3 validates the template's IANA timezone but never resolves a local date or
slot to a runtime instant. On both short and long daylight-saving transition
dates, the output remains a 1,440-minute civil template with
`dstTreatment: civil_time_unresolved`. This is deliberate: a future separately
approved runtime/time-resolution boundary must own any instant conversion,
ambiguous local time, or live clock behavior.

## Isolation and four-plane separation

Public reads require `station_id + template_id`; missing or out-of-scope
templates return `not_found`. Trusted internal template-ownership mismatches
return `station_reference_forbidden`. There is no route, persistence adapter,
filesystem, network, process, worker, runtime, encoder, relay, Icecast,
listener, DNS, or deployment adapter.

M4.3 belongs only to the Programming Control Plane. The Playout & Automation
Runtime, Source Encoder Layer, and Listener-Facing Icecast Layer remain
separately deployable and unavailable.
