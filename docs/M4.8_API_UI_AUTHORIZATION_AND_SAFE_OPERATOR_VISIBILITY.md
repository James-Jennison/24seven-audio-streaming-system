# M4.8 API/UI Authorization and Safe Operator Visibility

**Status: local-only and non-operational.** M4.8 adds an authenticated,
station-scoped fixture-status surface for M4 preview, review, approval,
publication, and rollback. It never invokes the M4.5–M4.7 boundaries.

`GET /api/v1/stations/{station_id}/schedule` returns content-free unavailable
states only. Named action routes require CSRF and programming RBAC, then fail
closed as `operation_unavailable`; they create no proposal, approval, published
artifact, active-pointer change, rollback, or audit payload. Out-of-scope
stations return `not_found`.

The accessible dashboard labels Schedule Visibility as fixture-status-only and
uses no action control. Runtime, encoder, relay, Icecast, listener, deployment,
media, persistence, and execution remain unavailable. Evidence contains only
station scope and safe state/category fields; it contains no schedule or media
content, credentials, tokens, CSRF values, paths, metadata, or SQL.

and separately approval-gated.
