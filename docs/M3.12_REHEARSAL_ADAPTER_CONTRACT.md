# M3.12 Rehearsal Adapter Contract

**Status: implementation candidate; opt-in deterministic double only.** The
`M3RehearsalAdapter` is separate from every disabled M3.3–M3.7 dispatcher. It
has no route, UI control, database, filesystem, process, network, provider, or
runtime adapter.

It accepts only an explicit rehearsal activation value, opaque fixture
reference, action identity, `id + station_id`, and idempotency key. Evidence is
content-free and distinguishes deterministic-double completion from unavailable
or failed metadata behavior. Cleanup and recovery are fixed rehearsal outcomes,
not host operations.

Out-of-scope reads return `not_found`; an internal cross-station reference
throws `station_reference_forbidden`. The adapter cannot start or contact
playout, encoder, relay, Icecast, listener, DNS, deployment, media tooling, or
an external metadata provider. It creates no standing operational authority.
